# AI for Data Stewards

## Project type

Training course with a coordinated set of learning and delivery artifacts.

## Purpose

Build practical AI fluency for data stewards, with an emphasis on trustworthy data practices, governance, quality, privacy, and responsible day-to-day use of AI-enabled tools.

## Planned artifact set

- Course charter and learning outcomes
- Course roadmap and module plan
- Session lesson plans and facilitator notes
- Presentation decks and speaker notes
- Learner exercises, case studies, and answer guides
- Data-steward AI prompt/playbook resources
- Assessments and completion criteria
- Reference glossary and curated resources

## Working assumptions

- The audience includes people responsible for data quality, definitions, metadata, access, and governance.
- Materials should be practical, role-aware, and suitable for adaptation across different organizational data environments.
- Individual artifacts will be added and versioned under this project as the course is developed.

## Status

Project in progress. The revised two-page proposal brief, the 21-page editable
participant workbook, and the 14-session AI for Data Guardians course plan have
been imported from the shared course materials and published as course
artifacts. Scope, audience detail, duration, and delivery format remain
available for further refinement.
