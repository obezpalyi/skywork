IT CLASS Prompt Engineering

Підсумок і exit ticket

Критерії якісного промпту
Зрозумілий результат
Чітка мета, яку модель має досягти у відповіді.
Достатній контекст
Вихідні умови, аудиторія та необхідні деталі для точної відповіді.
Формат і межі
Обмеження обсягу, структура відповіді, часові рамки, складність.
Безпека та перевірка
Без приватних даних; чіткі критерії для самоперевірки результату.
Exit ticket
Створи промпт для плану підготовки до контрольної з інформатики. Використай формулу: роль, аудиторія, контекст, обмеження, формат, критерій перевірки.
Домашнє завдання
Створи початкову, уточнену та фінальну версію одного промпту. Поясни, які покращення ти вніс на кожному кроці ітерації.
