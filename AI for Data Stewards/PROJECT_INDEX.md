# AI for Data Stewards

## Published course-package artifacts

This project package contains the following published artifacts:

1. **AI for Data Stewards — Proposal Brief**  
   Revised two-page proposal focused on practical and responsible AI use by practising data stewards.

2. **AI for Data Stewards — Participant Workbook**  
   Editable 21-page workbook with orientation, daily learning sections, exercises, worksheets, checks, reflections, safeguards, capstone work, and an action plan.

3. **AI for Data Guardians — Course Plan**  
   Fourteen-session curriculum covering AI literacy, data readiness, governance, risk, ethics, adoption, assessment, and continuous learning.

4. **AI for Data Guardians — Course Plan (HTML)**  
   Print-friendly HTML presentation of the course plan with module cards, session metadata, assessment strategy, and recommendations.

## Source project

The proposal brief and participant workbook were imported from **AI for Data Stewards Course Plan**. The course-plan materials were supplied through the shared AI for Data Guardians course-plan artifact.

## Package status

Core course-package artifacts are published. Additional session decks, facilitator notes, exercises, assessments, and reference resources can be added as the course is developed.
