IT CLASS Prompt Engineering

Що таке промпт

Промпт — це інструкція для моделі

Промпт — це інструкція або повідомлення, яке користувач передає моделі штучного інтелекту. Він може містити запитання, вихідні дані, приклад, роль, вимоги до формату та критерії якості. Саме від того, наскільки чітко сформульований промпт, залежить корисність і точність відповіді моделі.

Запитання
Чітко сформульоване питання, на яке модель має відповісти
Вихідні дані
Факти, цифри чи текст, на які спирається відповідь
Приклад
Зразок бажаного результату для наслідування
Роль
Хто «грає» модель: репетитор, редактор, критик
Формат
Структура відповіді: список, таблиця, план, код
Критерії якості
Вимоги до точності, обсягу та перевірюваності
Prompt engineering — це навичка, а не магія

Prompt engineering — це не набір «магічних слів» чи секретних фраз, які гарантують ідеальну відповідь. Це вміння чітко описати задачу, зрозуміти можливості моделі та оцінити отриманий результат.

Чітко описувати задачу та очікуваний результат
Розуміти, яку інформацію модель потребує для відповіді
Критично оцінювати та вдосконалювати отриманий результат
